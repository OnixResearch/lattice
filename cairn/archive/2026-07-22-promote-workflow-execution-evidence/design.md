# Design

Promotion is an exact set transformation over the archived completion receipt. A maintained 83-ID allowlist binds every identifier to one named test in its reviewed evidence file. The validator requires each marker immediately before that test, rejects missing or duplicate bindings, and confirms promoted IDs no longer appear in debt policy.

Tracey must move from exactly 181 missing IDs to exactly 98. Baseline minus current must equal the allowlist; current minus baseline must be empty; both missing sets must be unique and sorted; dangling markers must remain empty; and coverage must remain unsuccessful because unrelated debt remains.

The inventory is regenerated only after the exact transition passes. Historical completion evidence remains byte-bound to immutable snapshots and is not rewritten to include promotion-only marker lines.
