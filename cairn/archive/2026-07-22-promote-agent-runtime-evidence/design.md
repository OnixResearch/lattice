# Design: promote agent-runtime evidence

## Success contract

Baseline minus current MUST equal the exact 14-ID allowlist; current minus baseline MUST be empty; dangling MUST remain empty; coverage MUST remain invalid with 290 missing IDs.

Markers attach to the exact tests that establish each route, effect, fabric, authority, output, or reasoning clause. Historical completion validation strips only the expected marker-only lines before checking pre-promotion byte identities.

## Non-claims

This proves bounded linkage only, not arbitrary agent correctness, release readiness, or production readiness.
