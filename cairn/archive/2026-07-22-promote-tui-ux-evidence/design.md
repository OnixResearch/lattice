# Design

Promotion is an exact final set transformation over the archived completion receipt. A maintained 98-ID allowlist binds every identifier to one named test in its reviewed evidence file. The validator requires each marker immediately before that test, rejects missing or duplicate bindings, and confirms promoted IDs no longer appear in debt policy.

Tracey must move from exactly 98 missing IDs to zero. Baseline minus current must equal the allowlist; current minus baseline must be empty; both missing sets must be unique and sorted; dangling markers must remain empty; the baseline must remain unsuccessful; and final coverage must be successful with an empty missing set.

The inventory is regenerated only after the exact transition passes. Terminal inventory validation accepts only consistent `valid`/missing-set states, and the Nickel count contract permits zero while rejecting negative values. Historical audit and completion evidence remains byte-bound to immutable snapshots and is not rewritten to include promotion-only marker lines.

Before Octet identity migration, the TUI cache-write shell handles its `Result` and emits only a bounded failure diagnostic. The migration then requires exact normalized semantic-set equality: no candidate-only or resolved finding is accepted.
