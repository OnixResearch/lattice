## Design

`workflow::intent` consumes a Lattice-owned `CompileRequest`; this is explicitly not a Cairn wire DTO, authenticated producer receipt or grant. `SourceCohort` and `CompilerFacts` are explicit host-supplied facts. `Complete` is required shape/coverage, not independent proof that a producer supplied a complete snapshot. Restricted/incomplete pages and unsupported fields are rejected.

Admission bounds input bytes at the CLI and bounds obligations, dependency edges, alternatives, capabilities and evidence contracts in the pure core. Identities are canonical BLAKE3 references. Obligations, prerequisites, contracts and alternatives normalize before identity construction. Current source/context/policy and implementation/profile facts bind the entire plan. Names never become shell commands.

Choregraph owns dependency graph admission and cycle rejection. Its existing canonical machine descriptor supplies inspectable topology and graph identity; no second graph IR or scheduler is introduced. Plans have no effect declarations and no conversion to runtime grants. Required review and completion-only contracts remain explicit unresolved owner obligations, not successful execution verdicts.

The finite alternative fragment changes the implementation reference for named existing nodes while preserving all required nodes, dependencies and evidence. Unknown/unavailable choices fail. Structural workflow adaptation is only compared as bounded proposal data; any change requires Cairn/Kiln owner readmission and cannot modify the frozen plan.
