# Design: promote repository-validation evidence

## Success contract

Baseline minus current missing IDs MUST equal the exact 11-ID repository-validation allowlist. Current minus baseline MUST be empty, dangling markers MUST remain empty, and coverage MUST remain unsuccessful with 304 missing IDs.

## Local binding

Each marker is attached immediately to the maintained test that establishes its complete accepted boundary: three signing IDs, four source-closure IDs, two formatter IDs, and two Clippy IDs. The promotion validator rejects a missing test binding or any selected row that remains in the typed review policy.

## Historical evidence

The completion test accepts either the pre-promotion source or exactly one occurrence of every expected marker-only line, strips only those lines, and then checks the pre-promotion BLAKE3 identity. Any other source drift remains visible.

## Non-claims

The transition proves only exact marker linkage for this bounded tranche. It does not prove arbitrary repository correctness, complete traceability, release readiness, or production readiness.
