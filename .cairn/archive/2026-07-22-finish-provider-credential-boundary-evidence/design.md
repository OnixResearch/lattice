## Functional core and shell

A pure probe-result constructor maps reference identity and success state to a deterministic output. The thin shell invokes the provider and passes only success/failure state into the core. Integration tests own temporary files and executor orchestration.

## Adversarial audit

Tests must try provider errors containing plaintext, command timeout before a side-effecting shell, changed provider/key/field cache identities, changed resolved values, tampered vault bytes, workflow serialization, rendered JSON/debug output, and selected-marker absence. Partial evidence remains partial if any accepted clause lacks a direct observation.

## Claim boundaries

Command providers remain explicitly configured process adapters, not an authorization or sandbox boundary. The local vault remains a bounded existing mechanism, not a claim of audited cryptographic storage. Exact evidence does not prove external provider truth, arbitrary secret confidentiality, complete traceability, release readiness, or production readiness.
