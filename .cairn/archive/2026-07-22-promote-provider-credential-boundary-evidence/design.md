# Design: promote exact provider credential evidence

## Completion evidence

The promotion is complete only when baseline missing coverage is 336, current missing coverage is 329, baseline minus current equals the exact seven-ID allowlist, current minus baseline is empty, both receipts remain unsuccessful with zero dangling markers, every marker is locally attached, and current debt policy contains none of the promoted IDs.

## Marker bindings

- Cache identity binds to the provider/key/field/value-independence test.
- Both diagnostics rows bind to the fixed safe serialized probe test.
- Command success and timeout bind to the executor/side-effect test.
- Vault success and tamper bind to the workflow-file/executor/side-effect test.

Generated inventory, lifecycle completion tests, implementation names, and file scope are rejected as indirect evidence.

## Fail-closed checks

The pure validator rejects duplicate, unsorted, missing-removal, unrelated-removal, addition, dangling, successful-coverage, missing-binding, and stale-policy mutations with deterministic issue codes.

## Claim boundaries

This proves only maintained linkage for seven selected requirements, not provider truth, command sandboxing, vault cryptographic suitability, arbitrary confidentiality, complete traceability, release readiness, or production readiness.
