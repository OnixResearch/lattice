# Design: audit agent-runtime traceability

## Success contract

Exactly all 14 agent-runtime rows MUST receive reviewed classifications while the 304-item missing set remains unchanged. Exact rows require direct assertions for every accepted clause; partial rows name the unobserved boundary.

## Correlated portfolio passes

- Clause matching compares every GIVEN/WHEN/THEN clause with direct assertions.
- Effect tracing follows transport, model, tool, runner, and metadata observations.
- Authority tracing rejects implementation-only claims about absent mutation or fallback.

## Classification boundary

Seven rows are exact: existing-route compatibility, denied tools, bounded completion, turn exhaustion, runner execution, typed output, and plain content. Seven remain partial because current tests do not directly establish missing-route state preservation, complete credential omission, redacted no-fallback provider failure, pre-transport identity drift, inert authority-bearing output, all incomplete-status mappings, or zero-dispatch unsupported admission.

## Non-claims

Inventory rows create no evidence. Partial evidence is not near-complete correctness, and exact rows remain bounded to maintained fixtures.
