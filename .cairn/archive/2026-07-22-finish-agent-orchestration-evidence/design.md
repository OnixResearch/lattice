# Design

The pure status renderer now includes lifecycle, immutable revision, round, active run, pending proposal, remaining multidimensional budget, breach state, last event sequence/head, one next action, and fixed local-chain/remote-effect evidence scopes while omitting objectives, actors, terminal summaries, and secret content.

Core tests exercise the six audited gaps without I/O. Immutable audit snapshots preserve the earlier classification evidence. Completion validation requires all 39 rows exact, current-byte-bound, marker-free, and coverage-identical.
