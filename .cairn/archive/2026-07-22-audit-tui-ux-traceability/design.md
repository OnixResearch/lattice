# Design

The audit selects the exact 98-ID missing set from the archived workflow-execution promotion receipt. A deterministic builder assigns every ID to one bounded evidence family and one explicit classification. Exact rows require direct maintained assertions for the accepted scenario; partial rows identify the precise missing assertion or behavior boundary.

Reviewed evidence is copied into immutable repository-owned snapshots before any completion work. Every row records safe relative evidence paths and current file-byte BLAKE3 hashes. The maintained validator requires exact row cardinality, exact classification and rationale, safe evidence paths, matching snapshot hashes, unchanged failing coverage, no duplicate IDs, and no selected marker in maintained evidence.

Audit, completion, and promotion remain separate changes. The audit may report exact evidence, partial evidence, or an exact bounded absence; it cannot create Tracey linkage.
